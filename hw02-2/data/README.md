## 需要从 CSMAR 补下载的数据（2004-01-01 ~ 2013-12-31）

登录 [CSMAR](https://data.csmar.com)（中山大学已授权，校园网/VPN 访问），按以下 4 张表下载，**文件格式选 CSV（含字段说明）**，下载后放入本目录 `raw/`：

| # | 数据表 | 路径（CSMAR 栏目） | 时间范围 | 必选字段 | 保存文件名 |
|---|---|---|---|---|---|
| 1 | 资产负债表 | 财务报表系列 → 财务报表 → 资产负债表 | 2004-01-01 ~ 2013-12-31 | 证券代码、证券简称、统计截止日期、报表类型、货币资金(A001101000)、短期借款(A002101000)、长期借款(A002201000)、流动负债合计(A002100000)、负债合计(A002000000)、资产总计(A001000000)、所有者权益合计(A003000000) | `FS_Combas_2004-2013.csv` |
| 2 | 利润表 | 财务报表系列 → 财务报表 → 利润表 | 同上 | 证券代码、统计截止日期、报表类型、净利润(B002000000) | `FS_Comins_2004-2013.csv` |
| 3 | 股权性质文件 | 股东研究系列 → 中国上市公司股权性质文件 | 2004 ~ 2013 年度 | 全部字段（含 EquityNature、ActualControllerName） | `EN_EquityNatureAll_2004-2013.csv` |
| 4 | 基本信息年度表 | 公司研究系列 → 上市公司基本信息年度表 | 2004 ~ 2013 年度 | 全部字段（含 IndustryCode、LISTINGSTATE） | `STK_LISTEDCOINFOANL_2004-2013.csv` |

注意：
- 股票范围选**全部 A 股**（不要只选当前上市公司，需含 2005—2015 年间退市的公司）；
- 资产负债表 2004 年末数据用于 2005 年 ROA/ROE 的平均分母，**必须包含 2004 年**；
- 命名只要含表名关键字（`FS_Combas`/`FS_Comins`/`EN_EquityNatureAll`/`STK_LISTEDCOINFOANL`）即可被脚本识别；
- 已有 2014—2025 文件与本清单的 2004—2013 文件同时放在 `raw/` 下，管线自动合并（2014—2015 重叠年份按记录去重）。

## 分析变量与原始字段对应表

| 分析变量 | 口径 | CSMAR 字段 |
|---|---|---|
| 资产负债率 lev | 总负债 / 总资产 | A002000000 / A001000000 |
| bankloan | (短期借款 + 长期借款) / 总负债，两借款字段均非缺失才计算 | (A002101000 + A002201000) / A002000000 |
| 短期负债占比 st_liab_ratio | 流动负债 / 总负债 | A002100000 / A002000000 |
| ROA | 合并净利润 / 平均总资产（上年末与本年末均值） | B002000000 / mean(A001000000) |
| ROE | 合并净利润 / 平均所有者权益 | B002000000 / mean(A003000000) |
| Cash_TA | 货币资金 / 总资产 | A001101000 / A001000000 |
| 产权分类 | 按当年股权性质：国企→国有、民营→民营、外资/其他→其他、缺失→不明 | EN_EquityNatureAll.EquityNature |
| 行业（年末） | ≤2011 年：证监会 2001 版 J01 前缀；≥2012 年：证监会 2012 版 K70 | STK_LISTEDCOINFOANL.IndustryCode |
| 上市状态（年末） | 以年度信息表各年年末记录为准（含已退市公司历史记录） | STK_LISTEDCOINFOANL.EndDate |
